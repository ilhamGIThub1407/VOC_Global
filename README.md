# VOC Global

**Natural & Premium Traditions** — a B2B storefront for premium Indonesian spices, built for importers and food businesses in South Korea.

VOC Global connects Indonesian spice producers (black pepper, ginger, cinnamon, nutmeg, cloves, vanilla) with Korean buyers. Prices are shown in Korean Won (KRW) and sold in wholesale quantities.

## Features

- Product catalog with per-kg pricing in KRW
- Wholesale ordering: minimum 25 kg per product, custom quotation for orders above 1,000 kg
- Shopping cart with live item counter and total price
- Responsive layout with a mobile navigation menu
- Scroll-reveal animations
